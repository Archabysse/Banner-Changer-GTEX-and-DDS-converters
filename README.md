# Banner-Changer: GTEX and DDS Converters - Source Files

A conversion tool built by AI (claude.ai) designed to convert images between **GTEX** and **DDS** formats.

* **Credits:** Original converter was made by **Zoinkity**.
* **Purpose:** Made for **Changer of Banners**, an editor to add custom emblems to *Warhammer: Mark of Chaos*.
